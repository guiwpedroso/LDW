# 📚 Portal DSM

Sistema simples desenvolvido como atividade acadêmica para gerenciamento de **alunos e cursos**.

## 📌 Sobre o projeto

O **Portal DSM** permite realizar o cadastro e gerenciamento básico de alunos e cursos, simulando um pequeno sistema acadêmico.

## ✨ Funcionalidades

* 👨‍🎓 Adicionar alunos
* 📋 Visualizar alunos cadastrados
* 📚 Adicionar cursos
* 📋 Visualizar cursos cadastrados
* 🔄 Gerenciamento simples das informações
